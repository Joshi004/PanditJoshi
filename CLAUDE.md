## Project Overview

Website for Pandit Joshi, a Hindu priest serving the Atlanta, GA area. Built as a PWA with multilingual support (English, Hindi, Gujarati).

## Commands

```bash
npm run dev              # Start dev server (Vite HMR)
npm run build            # Production build (VITE_BASE=/ for Cloudflare, /PanditJoshi/ for GitHub Pages)
npm run lint             # ESLint
npm run preview          # Preview production build locally
npm run generate:panchang  # Pre-compute Hindu calendar data → src/data/panchang.json (must run before build)
npm run convert:samagri  # Convert samagri images to WebP using sharp
```

There are no tests in this project.

## Deployment

**Two deployment targets with different base paths:**

- **Cloudflare Workers** (primary): `VITE_BASE=/` (default). Configured via [wrangler.jsonc](wrangler.jsonc) with `not_found_handling: single-page-application`.
- **GitHub Pages**: `VITE_BASE=/PanditJoshi/`. CI workflow in [.github/workflows/deploy.yml](.github/workflows/deploy.yml) runs `generate:panchang` then `build` with this env var. A `spa-404` Vite plugin copies `dist/index.html` → `dist/404.html` for SPA routing on GitHub Pages.

## Architecture

### Routing & Layout

[src/App.jsx](src/App.jsx) wraps everything in `BrowserRouter` (with `basename` from `VITE_BASE`). Layout is `Navbar → AnimatedRoutes → Footer + WhatsAppButton`. Page transitions use Framer Motion `AnimatePresence` with a `PageTransition` wrapper on each route.

Routes: `/`, `/services`, `/services/:id`, `/puja-samagri`, `/videos`, `/blog`, `/blog/:slug`, `/contact`.

### Data Layer

All content lives in [src/data/](src/data/):

- **[services.js](src/data/services.js)** — Array of service objects. Each has `id` (URL slug), `icon` (name for `ServiceIcon`), `articleSlug` (links to blog post), `samagriId` (links to puja samagri list), and optional `videos` array / `kathaUrl`.
- **[pujaSamagri.js](src/data/pujaSamagri.js)** — Puja item lists keyed by `id` matching `samagriId` in services. Items have `category` from a fixed set: `powders | liquids | food | flowers | grains | incense | vessels | special`.
- **[blogPosts.js](src/data/blogPosts.js)** — Auto-imports all `src/data/articles/*.json` via `import.meta.glob`. Each JSON has `slug`, `title`, `excerpt`, `coverEmoji`, and `body` (array of `{heading, text}` sections).
- **[festivals.js](src/data/festivals.js)** — Festival definitions using Hindu calendar terms (masa/paksha/tithi) matched against panchang data. Has `articleSlug` for featured content near festival windows.
- **[panchang.json](src/data/panchang.json)** — Pre-generated Hindu calendar data for Atlanta, GA (lat 33.749, lng -84.388). Generated by `scripts/generatePanchang.js` using the `mhah-panchang` package. Covers current year + next year.

### Key Cross-Cutting Links

`services.js` → `blogPosts` (via `articleSlug`) → `pujaSamagri` (via `samagriId`). The `ServiceDetail` page assembles all three into one page. Adding a new service requires entries in all three data files to be fully featured.

### Animation System

[src/components/AnimatedSection.jsx](src/components/AnimatedSection.jsx) provides three exports:
- `AnimatedSection` — scroll-reveal wrapper with variants: `fadeUp | fadeIn | fadeLeft | fadeRight | scaleIn`
- `StaggerContainer` — staggers children animations
- `AnimatedItem` — individual staggered child

### Styling

Custom Tailwind palette in [tailwind.config.js](tailwind.config.js): `saffron`, `maroon`, `gold`, `ivory`, `brown`. Fonts: `Playfair Display` (heading) + `Lato` (body). Global utility classes in [src/index.css](src/index.css): `.btn-primary`, `.btn-outline`, `.section-title`, `.section-subtitle`, `.gold-divider`, `.card`.

### Multilingual Support

Google Translate widget is initialized hidden in [index.html](index.html). [src/components/LanguageSwitcher.jsx](src/components/LanguageSwitcher.jsx) provides the custom UI (EN/HI/GU) that writes the `googtrans` cookie and triggers the hidden select element. Language state is read from the cookie on mount.
